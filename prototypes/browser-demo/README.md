# Демонстрация пользовательского пути в браузере

Опубликованный демосайт: https://uzum-merch-login-demo.vercel.app/

Отдельный статический сайт для показа сценариев без запуска Docker. Весь контент вымышленный. Это **не OIDC-клиент, не настоящая авторизация и не защищённая многопользовательская система**.

Нет серверных обработчиков, БД, SMTP, Keycloak, токенов или секретов. Исходящий fetch запрещён CSP `connect-src 'none'`. Выбор тестового сотрудника, имитация активации приглашения и история заказов живут только в localStorage этого браузера. Их можно изменять средствами браузера — никакой реальный доступ они не дают.

Для технической проверки протокола используется отдельный [Docker-стенд](../identity-demo/README.md).

## Что попробовать

1. Корпоративный путь: выбрать Алину, проверить кадровые поля и оформить заказ.
2. Выбрать Бориса: доступен только Welcome pack и офис.
3. Выбрать сотрудника без доступа или заблокированного: увидеть отказ.
4. Персональная ссылка: ввести `DEMO-001`, проверить ПВЗ и повторное посещение.
5. Нажать «Сбросить демо» для нового показа. Сбрасываются только данные этого демосайта.

Не вводить реальные персональные данные или пароли. Телефон зафиксирован как вымышленный. Поля доставки демонстрируют интерфейс; их значения не сохраняются в истории. В production данные получения нужно сохранять и защищать на сервере.

Сайт размещается в отдельном проекте Vercel без environment variables. Рабочий мерчшоп и его конфигурация не изменяются.

## Проверки

Локально пройдены оба пути входа, неизменяемые кадровые поля, создание и сохранение тестового заказа, ограничения Welcome pack, отказ/блокировка, повторная активация, сброс и мобильная ширина. Lint новых файлов — без ошибок. Для повтора браузерной проверки нужны зависимости `../identity-demo` и Chromium:

```bash
# Сайт предварительно запустить локальным статическим HTTP-сервером на порту 3190.
node smoke-test.mjs
```

Vercel подтвердил готовность отдельного деплоя. Прямую браузерную проверку опубликованного адреса из облачной среды на момент публикации блокирует сетевой список среды; локальная проверка не заменяет её.
