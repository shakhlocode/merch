# Создание и размещение товаров

В «Новый товар» укажите название, раздел, один размер или размерный ряд и начальное количество каждого размера. Описание, цвет и фото необязательны. Для товара без размеров используйте ONE SIZE. Общий остаток считается по строкам, отдельное ручное значение не нужно. Система создаёт SKU автоматически.

Разделы: основной каталог, Welcome-pack или оба. Это отдельное свойство placement, а не старая категория «Одежда/Аксессуары». Существующие категории и материал сохраняются в БД, но в формах создания/редактирования они не запрашиваются. Старые товары по умолчанию остаются в основном каталоге; раздел можно изменить в редакторе товара.

Welcome-pack показывает активные товары из базы вместо прежнего статичного списка. Это информационный состав набора: выбор раздела сам по себе не создаёт заказ и не запускает автоматическую выдачу. Получение набора согласуется с администратором. В основном каталоге показываются активные товары с доступными остатками; нулевой остаток не даёт возможности заказать товар.

При показе в обоих разделах используется один товар с общими остатками. Карточка, размеры и начальные складские движения создаются в одной транзакции admin_create_product. Повторяющиеся сочетания размера и цвета, отрицательные/дробные количества и пустой размерный ряд отклоняются. Нулевые остатки допустимы. Новая операция доступна только активному администратору.
