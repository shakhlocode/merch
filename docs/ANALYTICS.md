# Выдачи и предупреждения об остатках

**Аналитика** (`/admin/analytics`) доступна только активным администраторам.
По умолчанию выбран текущий месяц по времени Ташкента. Укажите даты начала
и окончания включительно, раздел, способ получения и при необходимости поиск
по товару, размеру, цвету или SKU. Нажмите **Применить**.

Сводка, товары/размеры, дни и подробные строки учитывают только статус
`received` по `received_at`, а не дате оформления. Удалённые отправки входят
после подтверждённого получения; просто отправленные посылки не считаются
выданными. Повторный скан не создаёт дополнительной выдачи. Поиск оставляет
только совпавшие позиции: количество заказов считается уникально по этим
позициям, количество штук — суммой их количества. Исторические названия,
размеры и цвета берутся из заказа и сохраняются при изменении/архиве товара.

В каждом из шести разделов есть **Экспорт CSV**. Файл содержит весь
отфильтрованный отчёт; на странице при больших результатах показываются
первые 200 строк с пояснением. Агрегация выполняется в PostgreSQL и не
обрезается лимитом PostgREST в 1000 строк. CSV: UTF-8 с BOM, разделитель `;`,
экранирование значений и защита от формул. Пустой отчёт сохраняет заголовки.
На дашборде доступны CSV сводки, списков последних заказов/активности и всех
предупреждений. Склад и заказы сохраняют прежние CSV; в заказы добавлена дата
фактического получения, в склад — порог варианта.

**Остатки и предупреждения — на текущий момент**, не исторический снимок
выбранного периода. Учитываются все действующие товары и варианты; из
фильтров на них влияет только поиск. CSV содержит время снимка в Ташкенте.
Архивные товары и отключённые варианты не создают предупреждений, но их
прежние выдачи остаются в отчёте.

По умолчанию предупреждать при **≤ 5 доступных штук**. Для каждого размера
и цвета в редакторе товара: **Порог предупреждения → Сохранить вариант**.
Допустимы целые 0–1000000; 0 предупреждает только при нулевом остатке.
Доступно = общий остаток − резерв. Сам порог не изменяет количество/резерв.
Сообщения видны в складе, на дашборде и в аналитике. Почтовые и push-уведомления
не подключались. Новые варианты также получают порог 5 по умолчанию.

Миграция: `20261015001300_inventory_analytics.sql`. Выполняется один раз после
предыдущих миграций; добавляет поле настройки, права изменения поля с RLS,
индекс по дате получения и два RPC только для администраторов. Бизнес-функции
резервирования и выдачи не изменяются. Проверки `npm run db:test` включают
границы дня, размеры, фильтры, архив, резерв, права и отчёт на 1007 заказов.
