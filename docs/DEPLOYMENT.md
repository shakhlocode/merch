# Развёрнутая копия

- Сайт: https://uzum-merch-taupe.vercel.app
- Vercel: https://vercel.com/shakhlo/uzum-merch
- Supabase: https://supabase.com/dashboard/project/ujdvmygoarxiudttaure
- Регион БД: Frankfurt (`eu-central-1`). Создан отдельный проект; прежний
  неактивный проект аккаунта не изменён.
- Администратор: `shahlo.kham@gmail.com`. Пароль не назначен автоматически:
  войдите на сайте по письму и установите свой пароль.

База уже установлена. Не запускайте свежую миграцию повторно в этом проекте.
Товары, кадровый справочник и старые заказы не перенесены. Все временные товары,
фото, заказы и аккаунты функциональных проверок удаляются после проверки.
Для заказов заполните кадровый справочник реальными датами найма и добавьте
товары/варианты/поступления. Категории добавляются через Supabase Dashboard.

Проверены: облачная схема и RLS, вход по паролю, создание пароля, страницы
каталога/профиля/заказов/админки, создание товара и варианта, поступление,
загрузка фото, создание заказа, отображение заказа, отправка и отмена,
возврат остатков. Проверка SMTP-доставки писем не выполнялась. Стандартная
почта Supabase ограничена адресами участников организации; для остальных
сотрудников нужен собственный SMTP в Authentication settings.

Первый деплой выполнен через Vercel API из подготовленных файлов.
Для автоматических деплоев установите GitHub-приложение Vercel с доступом к
`shakhlocode/merch`, затем подключите репозиторий в Vercel → Project Settings →
Git. Восстановленные файлы находятся в ветке `codex/restore-merch-system`.
Для работы с основной веткой сначала перенесите изменения в `main` через PR.
Не переключайте production branch на другую ветку с непроверенными изменениями.

Публичный URL Supabase и публичный anon key настроены в Environment Variables
Vercel. Service-role key и персональные токены в приложение не включены.
В этой машине есть игнорируемый `.env.local` с публичными настройками для
разработки. Ключи и токены не коммитятся. Инструкции для новой независимой
копии и описание восстановленных правил находятся в [SETUP.md](SETUP.md).
